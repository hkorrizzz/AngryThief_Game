Проект представляет собой подобие популярной игры Angry Birds, разработанный на Unity (2025). Игрок управляет вором, запуская её из рогатки, чтобы разрушать конструкции и забирать монеты.

**Основные классы**
- AngieBird – запуск, физика, поворот, коллизии, звук
- Baddie – здоровье, урон, смерть, частицы
- SlingShotHandler – рогатка, захват, оттягивание, линии, запуск
- GameManager – выстрелы, победа/поражение, рестарт, уровни
- CameraManager – обзорная и следящая камера
- SoundManager – воспроизведение звуков
- IcinHandler – иконки оставшихся выстрелов
- MainMenu – меню, выход, переход на уровни
